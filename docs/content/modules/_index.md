One artifact per SDL library. The core is `sdl3`; the satellites add text, images, and
audio and pull the core in transitively.

- **[sdl3](/modules/core/)** — window, renderer, drawing, geometry, events, input.
- **[sdl3_ttf](/modules/ttf/)** — TrueType text rendering.
- **[sdl3_image](/modules/image/)** — image loading and PNG saving.
- **[sdl3_mixer](/modules/mixer/)** — audio playback.
